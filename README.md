# Anastasia ♡

Расширение для Google Chrome
![Anastasia](Anastasia.png)

## Установка

Откройте [install.html](https://htmlpreview.github.io/?https://github.com/bylka2W/Anastasia/blob/main/install.html) в браузере и следуйте инструкциям.

## Использование

1. Откройте [chat.deepseek.com](https://chat.deepseek.com)
2. Нажмите кнопку **A** в правом нижнем углу
3. Anastasia готова ♡

промт насти немного дает буста в рассуждение и понимании задач от пользователя

PS: нет деняг на API))) так что вот так воооот..
