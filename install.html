Расширение для Google Chrome

Установка

1
Скачайте расширение с GitHub
2
Распакуйте архив в любую папку
3
Откройте chrome://extensions в адресной строке
4
Включите Режим разработчика (Developer mode) в правом верхнем углу
5
Нажмите Загрузить распакованное расширение (Load unpacked) и выберите папку Anastasia
6
Готово! Откройте chat.deepseek.com и нажмите кнопку A в правом нижнем углу
Скачать расширение Открыть DeepSeek
Важно: Расширение работает только на chat.deepseek.com. Не закрывайте папку с расширением — иначе Chrome удалит его.
